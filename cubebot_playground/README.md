# CubeBot Playground

Заготовка проекта для обучения и тестирования CubeBot в MuJoCo Playground.

## Структура

- `cubebot_playground/` — модель робота, среды, награды и ландшафты.
- `learning/` — обучение PPO и запуск обученной политики.
- `scripts/` — просмотр модели и быстрые проверки среды.
- `checkpoints/` — локальные контрольные точки обучения.

Установка в режиме разработки:

```bash
python -m pip install -e .
```
